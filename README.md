# TDE - Pilha e Fila em Java

Projeto desenvolvido para a disciplina de Estrutura de Dados contendo 5 exercícios práticos com estruturas de **Pilha** e **Fila** em Java, sem o uso da biblioteca `Scanner`.

## 📌 Exercícios Resolvidos

1. **Par e Ímpar (Pilha):** Separação de números pares e ímpares com regra de desempilhamento no zero.
2. **Palíndromo (Pilha):** Verificação de palavras usando inversão via pilha.
3. **Parênteses Balanceados (Pilha):** Validação de expressões matematicamente balanceadas `()`, `[]`, `{}`.
4. **Atendimento Bancário (Fila):** Simulação de fila de atendimento com tempo acumulado.
5. **Fila de Impressão (Fila):** Simulação de impressão com avisos a cada 2 documentos e verificação de maior arquivo.
